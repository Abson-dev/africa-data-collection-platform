# Form templates

XLSForms are generated by [`build_templates.py`](build_templates.py), so changes can be reviewed as code. Don't edit the `.xlsx` files by hand; edit the script and run:

```bash
pip install openpyxl pyxform
python forms/build_templates.py
xls2xform forms/templates/example_household_sms.xlsx /tmp/out.xml   # convert + ODK Validate (needs Java)
```

| Template | Purpose |
|---|---|
| `templates/consent.xlsx` | Start every form that collects personal data from this. It has a required consent question; the rest of the form only shows if the respondent agrees. EN + FR. |
| `templates/sms_partial.xlsx` | **Upload to Central once per project.** The Bridge service writes one submission here for each SMS fallback. Field names must match `PartialXml.kt`. |
| `templates/example_household_sms.xlsx` | Example of marking fields for SMS fallback. |

## Marking fields for SMS fallback

1. In the **settings** sheet, add a `namespaces` column with:
   ```
   adc="https://github.com/Abson-dev/africa-data-collection-platform/xforms"
   ```
2. In the **survey** sheet, add a `bind::adc:sms` column and put `yes` on each field to send.

Rules of thumb:
- Choose the few fields a supervisor needs **before** the full record arrives: location, an ID, the urgent answer.
- Never mark media (photo, audio, video). Short text, numbers, choices and GPS points are fine.
- The budget is about 290 bytes after compression, roughly 20–40 short fields. The app warns if a record doesn't fit.
- Changing which fields are marked needs a new form **version**, because the SMS identifies fields by position.
